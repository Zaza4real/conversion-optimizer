## Shopify Re-Review Checklist

Use this checklist before replying to Shopify and clicking submit.

- [ ] In app listing **Pricing details**, include:
  - Growth: `$19` monthly
  - Pro: `$29` monthly
  - Pro Annual: `$290` annual
  - No free trial (if still true)
- [ ] In app listing media (screenshots, feature image, icon), remove any explicit pricing text like `$19`, `$29`, `/mo`, `/year`.
- [ ] Save and republish listing media assets after the pricing text is removed.
- [ ] Reinstall app on a dev/test store and confirm app home shows all 3 plans (Growth, Pro, Pro Annual).
- [ ] Start checkout for Pro Annual and confirm Shopify billing shows annual interval.
- [ ] Run a fresh scan and verify recommendations show:
  - `Applies to`
  - `Issue found`
- [ ] Export CSV and verify columns include:
  - `Applies to`
  - `Issue found`
- [ ] Verify cancellation still works from app (`Cancel subscription`).
- [ ] Verify no UI overlap/truncation on plan cards and action buttons in desktop and mobile.

### Notes for reviewer response

- Mention that pricing options are now fully consistent between app and listing.
- Mention that listing images no longer contain pricing text.
- Mention that recommendation details now identify specific product/store target and detected issue.
